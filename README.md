## About the Project
This project is designed to identify a user's skin type and provide suitable skincare routine recommendations based on their skin characteristics.

## Purpose
The purpose of this project is to help users understand their skin type and choose a basic skincare routine.

## Note
The recommendations are for general information only and are not a substitute for professional skincare advice.
